# 🎓 Marksheet CGPA Calculator  

A simple GUI application built using **Python's Tkinter** to calculate **CGPA** based on grades and credits.

---

## 📌 Features  

✔️ **User-friendly GUI** – Simple and intuitive interface.  
✔️ **Grade to Mark Conversion** – Automatically converts grades (A, B, C, D) to marks.  
✔️ **CGPA Calculation** – Computes total marks and CGPA based on credit hours.  
✔️ **Instant Result Display** – Results are shown dynamically upon submission.  

---

## 🛠️ Tech Stack  

| **Technology** | **Usage** |
|---------------|----------|
| Python | Core programming language |
| Tkinter | GUI development |

## 🏗️ Installation & Setup  

Follow these steps to run the project on your **Windows terminal**:

### 🔹 Step 1: Install Python  
Ensure you have **Python 3.x** installed. If not, download it from:  
🔗 [Python Official Website](https://www.python.org/downloads/)  

### 🔹 Step 2: Clone the Repository  

```sh
git clone https://github.com/your-username/Marksheet-CGPA-Calculator.git

cd Marksheet-CGPA-Calculator
```
### 🔹 Step 3: Run the Script
```sh
python marksheet.py
```
